# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub private vulnerability reporting:
<https://github.com/spicysharkco/sharkline/security/advisories/new>. Please do not
open a public issue or pull request for it.

Say which version you ran (`sharkline --version`), what you did and what happened.

## Supported versions

sharkline is a 0.x project. Only the latest release gets fixes.
